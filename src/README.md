# Remote Arduino Lab — авторизация и очередь заданий

Учебная лаборатория для Arduino Uno R3: видеопоток, выбор COM-порта, вход по учётной записи и очередь прошивок. Задания выполняются строго по одному; каждый студент видит только свои задания, преподаватель с ролью `admin` видит все.

## Требования
- Windows 10/11
- Node.js 18+
- FFmpeg по пути `C:\ffmpeg\bin\ffmpeg.exe`
- Arduino IDE (для `avrdude.exe` и `avrdude.conf`)
- Arduino Uno R3 подключена к компьютеру лаборатории

## Первый запуск
1. Распакуйте архив в отдельную папку, например `C:\RemoteArduinoLab`.
2. Запустите `start-lab.bat` один раз — скрипт установит npm-зависимости и запустит сервер.
3. Остановите сервер клавишами `Ctrl+C` в окне командной строки.
4. Создайте учётную запись преподавателя:
   ```bat
   node manage-users.js add teacher admin
   ```
   Введите длинный пароль не менее 12 символов. Пароль не отображается при вводе в обычной консоли Windows; если консоль показывает ввод, всё равно не пересылайте пароль другим.
5. Создайте студентам отдельные учётные записи:
   ```bat
   node manage-users.js add student01 student
   node manage-users.js add student02 student
   ```
6. Снова запустите `start-lab.bat`.
7. На компьютере лаборатории откройте `http://localhost:3000`. Ученики из доверенной сети Radmin VPN открывают `http://АДРЕС_RADMIN:3000`.

## Роли и очередь
- `student`: вход, просмотр камеры, выбор COM-порта, отправка `.hex`, просмотр статусов своих заданий, отмена задания пока оно ожидает очереди.
- `admin`: всё то же, плюс просмотр заданий всех студентов.
- Одновременно выполняется только одна прошивка. У каждого пользователя может быть не более трёх активных заданий.
- Статусы: в очереди, выполняется, успешно, ошибка, отменено.
- Очередь и сессии находятся в памяти процесса: после перезапуска сервера текущие сессии исчезают, а задания, оставшиеся в очереди, не восстанавливаются. Не перезапускайте сервер во время прошивки.

## Управление пользователями
Создавайте пользователя из папки проекта:
```bat
node manage-users.js add <логин> student
node manage-users.js add <логин> admin
```
Логин: 3–32 символа, латиница, цифры, `.`, `_`, `-`. Пароль: минимум 12 символов. Хеши паролей хранятся в `users.json`, открытые пароли не сохраняются. Для удаления учётной записи остановите сервер, откройте `users.json`, удалите соответствующий объект и сохраните файл. Не удаляйте последнего администратора.

## Arduino
1. В Arduino IDE выберите Arduino Uno.
2. Используйте «Скетч → Экспорт бинарного файла» и выберите `.hex` без `with_bootloader`, если есть.
3. Войдите в веб-интерфейс, выберите COM-порт и отправьте `.hex`.
4. Сервер проверит порт в момент выполнения задания и вызовет AVRDUDE с фиксированными параметрами из `config.js`.

Если `avrdude` не найден, задайте `avrdudePath` и `avrdudeConfigPath` в `config.js`. Стандартная скорость — 115200 бод; для старого загрузчика может потребоваться 57600.

## Безопасность
- Сервер слушает сетевые интерфейсы, чтобы быть доступным через Radmin VPN. Используйте только доверенную сеть; не публикуйте порт 3000 в интернете.
- Пароли не хранятся открытым текстом. Сессия хранится в HttpOnly cookie с `SameSite=Strict` и ограниченным сроком действия.
- Пользовательские запросы не могут задавать команды AVRDUDE, модель микроконтроллера или произвольный путь к файлу.
- Преподаватель должен выдавать каждому студенту отдельный логин и не использовать общий пароль.
- Это учебный прототип. Перед реальным использованием в учреждении рекомендуется HTTPS/VPN, резервное копирование журнала и проверка политики доступа брандмауэра.

## Камера
Если видео не отображается, проверьте `cameraName`, `ffmpegPath` и закройте другие приложения, использующие камеру.


## Последовательный порт (Serial Monitor)
В веб-интерфейсе появился раздел «Последовательный порт (Serial Monitor)»:
- выбрать COM-порт и скорость (например, 9600 или 115200 бод);
- открыть и закрыть порт;
- получать данные от скетча в реальном времени;
- отправлять текстовые команды с необязательным CR+LF;
- очищать окно входящих данных.

В Arduino-скетче скорость должна совпадать, например:
```cpp
void setup() {
  Serial.begin(9600);
  Serial.println("Arduino ready");
}
void loop() {
  if (Serial.available()) {
    String command = Serial.readStringUntil('\\n');
    Serial.print("Получено: ");
    Serial.println(command);
  }
}
```
При работе Serial Monitor очередь прошивок ждёт, пока порт не будет закрыт. Открыть порт может один пользователь за раз; владелец может отправлять данные и закрывать соединение. Преподаватель может закрыть соединение. Не открывайте тот же COM-порт в Arduino IDE Serial Monitor одновременно.

Для поддержки COM-порта добавлена зависимость `serialport`. После обновления проекта запустите `start-lab.bat`, чтобы npm установил её. Если Windows не разрешает доступ к порту, закройте Arduino IDE и другие приложения, использующие COM-порт.
